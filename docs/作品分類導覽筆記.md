# 作品分類導覽筆記

## 問題：從詳細頁返回時，分類會回到水晶花

### 現象

在「布製品」或「皮件」列表中開啟作品詳細頁後，按下「回到作品列表」會回到手作作品頁的預設分類「水晶花」，使用者必須再次手動選擇原本的分類。

### 原因

詳細頁原本將返回連結固定指向 `/handmade`。分類選取狀態只存在列表元件的記憶體中；元件重新建立時，會使用預設值 `crystal-flower`，因此無法得知使用者原本從哪個分類進入。

### 解決方式

將分類狀態放入網址查詢參數，並讓列表、作品卡片與詳細頁共用這個來源：

- 布製品：`/handmade?category=fabric`
- 皮件：`/handmade?category=leather`
- 水晶花：`/handmade?category=crystal-flower`
- 水晶花子分類：`/handmade?category=crystal-flower&level=junior`

列表頁會讀取網址來設定目前分類；點選分類或水晶花子分類時，會更新網址。作品卡片進入詳細頁時帶上分類資訊，詳細頁的返回連結則依作品本身的分類產生相同的列表網址。

### 後續維護原則

新增手作分類時，請同步處理以下項目：

1. 在 `ProjectListView.vue` 的 `handmadeCategories` 加入分類識別值。
2. 每筆作品資料都要設定相同的 `category`。
3. 若新分類有子分類，將子分類寫入網址參數，並在列表頁解析與驗證。
4. 作品卡片與詳細頁的連結都應保留分類參數，避免返回時失去使用者所在位置。

這種做法也使網址可直接分享、重新整理後仍保留原本的作品分類。
