# 作品圖片管理筆記

## 這次遇到的問題與解決方式

### 問題一：圖片寫了路徑卻沒有顯示

先前使用了這種寫法：

```js
cover: '/src/img/flower/junior/junior-01-1.jpg'
```

這不是可靠的作品資料寫法。Vite 在正式建置、尤其部署到 GitHub Pages 後，不會把它當成需要處理的本機圖片網址。

**解法：**本機圖片改用 `imagePaths`，讓程式自動找到圖片並產生可用網址。

```js
imagePaths: ['flower/junior/junior-01-1.jpg']
```

### 問題二：使用 `localhost` 圖片網址

先前使用了這種寫法：

```js
cover: 'http://localhost:5173/vue-portfolio/src/img/leather/card-holder-01-1.jpg'
```

`localhost` 只指向自己的電腦；網站部署後，其他人與 GitHub Pages 都無法存取它。此外，當時專案內也沒有對應的皮件圖片檔案。

**解法：**將圖片放到專案的 `src/img/leather`，再填入相對路徑：

```js
imagePaths: ['leather/card-holder-01-1.jpg']
```

### 問題三：擔心每張圖片都要 `import`

不需要。`projects.js` 已用 `import.meta.glob` 自動讀取 `src/img` 下的 JPG、PNG、WebP 與 AVIF 圖片。你只需要填 `imagePaths`，不用逐張寫 `import`。

### 問題四：詳細頁只能顯示一張圖片

現在一件作品可使用 `imagePaths` 放一張、兩張或更多張圖片。第一張是卡片封面，詳細頁則會依順序顯示全部圖片。

### 問題五：詳細頁的直式圖片被裁切

詳細頁曾將圖片設定為固定高度，並使用 `object-fit: cover`：

```css
height: min(58vw,620px);
object-fit: cover;
```

這種寫法適合卡片縮圖，因為它可以讓卡片大小一致；但直式圖片會為了填滿橫式框而裁掉上下內容，手機版的固定正方形高度也會裁切圖片。

**解法：**詳細頁圖片使用原始比例，限制最大可視高度並置中：

```css
.cover {
  display: block;
  width: auto;
  max-width: 100%;
  height: auto;
  max-height: 76vh;
  max-height: min(76svh,760px);
  margin-inline: auto;
}
```

這個設定同時適用於桌面與手機：直式、橫式圖片都會完整顯示，直式圖片也不會高到超過一個螢幕。卡片圖片則可維持原本的裁切方式，讓卡片排列整齊。

## `cover` 和 `imagePaths` 的用途

`cover` 不是 Vue 的特殊名稱，而是本專案用來提供卡片與詳細頁顯示圖片的欄位。

- 本機圖片：請使用 `imagePaths`。程式會自動把第一張轉成 `cover`。
- 網路圖片：可直接使用 `cover: 'https://...'`。
- 作品卡片使用 `cover`，因此永遠顯示第一張圖。
- 作品詳細頁使用 `images`，因此可顯示所有圖片。

## 圖片放哪裡？

將本機圖片放在 `src/img` 下。例如水晶花初級作品可放在：

```text
src/img/flower/junior/rose-02-1.jpg
src/img/flower/junior/rose-02-2.jpg
```

皮件作品可放在：

```text
src/img/leather/card-holder-01-1.jpg
```

不用手動 import 圖片，也不要使用 `localhost`、`/src/...` 或電腦的完整路徑。

## 新增一件本機圖片作品

在 `src/data/projects.js` 的 `projects` 陣列中，複製一筆現有作品並修改內容。圖片欄位使用 `imagePaths`：

```js
{
  id: 'crystal-flower-junior-02',
  type: 'handmade',
  category: 'crystal-flower',
  level: 'junior',
  title: '新作品名稱',
  year: '2026',
  imagePaths: [
    'flower/junior/rose-02-1.jpg',
    'flower/junior/rose-02-2.jpg'
  ],
  description: '作品介紹',
  tags: ['水晶花', '初級'],
  materials: '材料名稱'
}
```

- 只放一張圖：`imagePaths` 只留一個路徑。
- 放兩張或更多：在陣列中依序新增路徑。
- 第一張圖會是作品卡片封面；點進詳細頁後會顯示全部圖片。

## 使用網路圖片

若圖片放在網路上，可保留 `cover`：

```js
cover: 'https://example.com/image.jpg'
```

網路圖片沒有填 `imagePaths` 時，詳細頁會顯示這一張 `cover` 圖片。

## 圖片沒有顯示時

依序檢查：

1. 圖片是否真的放在 `src/img`。
2. `imagePaths` 的資料夾、檔名和副檔名是否與檔案完全相同。
3. 第一張圖是否放在你想當封面的圖片位置。
4. 圖片有直式也有橫式時，確認詳細頁 `.cover` 維持 `height: auto`，不要加入固定高度與 `object-fit: cover`。
5. 重新整理頁面；瀏覽器主控台出現「找不到作品圖片」時，表示路徑或檔名不相符。
